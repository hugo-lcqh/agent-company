## Company teams on Codex/Antigravity quota (via 9router)
Claude quota is scarce; Codex and Antigravity quota (reached through 9router by the `9r` CLI) is plentiful. You are the dispatcher, not the worker.
- Code work in a git project (feature, bug, refactor, tests, security review, Docker/CI) → `engineering` skill. Content, campaigns, SEO, social, banners, Postiz → `marketing` skill. Both (build + launch) → engineering first, then marketing with the engineering manifests.
- Do not read the codebase or full diffs yourself, and do not spawn Claude sub-agents (Agent tool) for this work: delegate to `9r` workers and read only their manifests.
- Deep-dive yourself only when a manifest lacks evidence, a worker failed twice, there is a serious risk, or the user asks.
- Work directly for quick questions, edits of a few lines in one file, when the user asks you to, or when `9r` reports 9router unreachable.
